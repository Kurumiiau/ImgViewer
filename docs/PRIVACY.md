# ImgViewer 隐私协议

生效日期：2026 年 10 月 4 日。应用作者：Kurumiiau。

ImgViewer 用于浏览、播放和编辑用户授权访问的图片。本说明适用于 ImgViewer 本身；用户自行选择的文件提供方、分享接收应用和 GitHub 服务，按各自的隐私规则处理数据。

## 1. 照片与权限

仅在用户授予照片权限或选择文件后读取相关图片。为了排列、搜索和显示图片，会读取文件名称、格式、大小、图集、图片尺寸、拍摄或修改时间等信息。支持仅授权部分照片；拒绝照片权限后，仍可通过文件选择器打开单独授权的文件。旧版 Android 保存编辑副本时可能需要存储写入权限。应用不申请全盘文件访问、定位、相机、麦克风或通讯录权限。

## 2. 本地记录与副本

收藏、导入记录、排列设置和图片缓存保存在手机本地。无法持久获得文件访问权限时，会保存一份应用私有导入副本。编辑结果另存为手机 Pictures/ImgViewer 中的 PNG，保留原文件；编辑动图导出的是静态首帧副本。特别大的图片可能按设备内存预算缩小。编辑副本不会保留原文件中的 EXIF、GPS 或 HDR 元数据。

## 3. 联网、统计与广告

应用本身不申请网络权限，不向作者或其他服务器上传照片、收藏或导入记录，不包含账户系统、广告或统计跟踪服务。用户选择的云文件提供方或分享接收应用可能自行联网，这些行为由相应服务处理。

## 4. 分享与删除

仅在用户主动选择分享时，向用户选择的接收应用提供所选原文件的读取授权。无法直接分享的私有文件会生成临时分享副本；超过 48 小时的旧分享副本会在后续分享准备时清理。接收应用可能保存或转发文件，请按其规则管理。

删除原文件前会显示确认，受系统保护的照片还需要系统确认。批量删除中取消后会停止处理剩余文件；只读或无法删除的文件会保留并提示。已成功删除的原文件无法由 ImgViewer 撤销。

## 5. 数据管理

用户可在系统设置中撤回照片权限、清除应用数据或卸载。清除应用数据或卸载会移除收藏、设置、导入记录、私有导入副本与应用缓存，不会删除手机媒体库的原照片或已导出的编辑副本。应用关闭了 Android 自动备份及应用数据迁移功能。

## 6. 联系与变更

如对本应用的数据处理有疑问，可在作者 Kurumiiau 的 ImgViewer GitHub 仓库提交 Issue。反馈时请自行避免附带个人照片或其他敏感信息。隐私说明随应用版本更新，并会标明新的生效日期。
